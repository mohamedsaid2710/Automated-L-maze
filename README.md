# Automated L-maze

Pseudoword distractors for lexicality-maze (L-maze) experiments: give it your sentences, get back a
matched, orthographically legal pseudoword for every word, ready for PsychoPy, jsPsych or PCIbex,
plus a report of how well each distractor meets the constraints.

Designed so that a new language, in any script (Latin, Hebrew, Arabic, Devanagari, Chinese, ...),
needs only a small profile file and a word list.

**Status:** in development; not usable yet.

Companion to the A-maze distractor tool
[Distractor_software-](https://github.com/mohamedsaid2710/Distractor_software-); both use the same
input and output formats (`tag;id;sentence[;labels]`).

Mohammed Said, Institute of Linguistics, University of Stuttgart.
